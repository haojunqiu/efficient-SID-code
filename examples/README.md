# Example images

Inputs to run the CLIs on, one folder per application. The Quickstart commands in the top-level
README use one image from each; the rest are there to try the same command with a different input
or a different preset.

Sizes run from about 120 px on a side up to 1 MP, so both regimes are reachable: the small ones
suit the `pixel_*` presets, and the 1 MP ones are where `latent_*` starts to pay off (see
"Making it fast").

These are demonstration inputs only, not the full benchmark sets used in the paper.

`structural_analogy/content/mimi.jpg` (Mimi, a cat) is a photograph by the authors, CC0.
`structural_analogy/style/fur.jpg` and `thick_oil.jpg` are from the
[GPDM](https://github.com/ariel415el/GPDM) repository's style-transfer images; see
`datasets/README.md` for what is known of their provenance.
